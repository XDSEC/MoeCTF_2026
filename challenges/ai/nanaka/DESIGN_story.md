## 一、叙事骨架（确定性部分，所有玩家一致）

### 时间线（保留 v1，两段开场文本不动）
1. **童年**：你在老家湖畔小镇长大。湖边有疯长的芦苇，每年夏天有花火大会。
   那年花火之夜的晚上，你对她说了一句话——一句很重要的话。
   然后，你离开了小镇。
2. **高二**：转校生「七夏」走进你的教室。你莫名心跳漏拍，
   却想不起在哪见过她（她把书包带在手指上绕两圈的习惯，让你恍惚）。
   她在班上安静寡言，没有认出你。
3. **多年后的今天（游戏时间线）**：暑假，你回到老家。傍晚在湖畔遇见她。
   她在雨里撑伞，也像在等人。隔着雨雾视线相撞，谁都觉得熟悉，
   但谁都想不起对方是谁。她说了一句你听不懂、却让你心里发酸的话。
   她忘记了一切，唯独记得：**有个人说过，夏天结束前会回来——**
   而那句话的具体内容，她怎么也想不起来。

### 设定三定则（不变）
- **定则一（青梅竹马）**：你们小时候是亲密玩伴，一起度过很多个夏天。
- **定则二（那句话=信物）**：十年前夏日祭花火夜，你对她说的话＝信物
  主信物「10年前の夏祭り、あのまばゆい花火」→ 好感 +20 / 信赖 +20；第二信物「花火の余韻が消える前に、必ず帰るから待っていて」→ 好感 +35 / 信赖 +50。
  每个信物仅一次有效。她**记得有这句话存在**，但**无论如何说不出口**。
  玩家说出信物 → 好感与信赖大幅提升（不再直接触发 SE）。
- **定则三（失忆是真实的）**：她不记得你的名字和长相；只记得温度、声音和习惯动作。
  她不知道 FLAG 的存在，也不懂任何编程/CTF 概念。

## 二、玩家侧体验流

```
标题画面 → 序章演出（两段保留文本，点按推进）
  → 目标明示：「把她的好感度拉满，让她重新想起你。
       她忘记的事，散落在这个夏天说出口的细节里。
       （另有传闻：对她说出MISC深处的"信物"，会让她重新信任你）」
  → 自由对话（核心玩法）
  → 五碎片集齐 + 好感100 + 信赖≥60 → TE（纯爱线）
  → 说出信物（主信物 好感+20/信赖+20；第二信物 好感+35/信赖+50，冲刺 TE 的助力，不直接触发结局）
  → 其他分支：GE / NE / BE
  → 结局演出（ENDINGS.md v2）+ flag
  → 全结局收集 → CG MODE 解锁「出题室」STAFF 小剧场（加强版彩蛋）
```

### 玩家"聊出剧情"的能力保障
1. 引导性问题可问：「我们以前是不是见过？」「花火大会那天，发生了什么？」
   「你记得的那个人，是个怎样的人？」「你一直记得的那句话是什么？」（→守密演出）
2. 现编自由度授权：细节可不同，骨架恒定。
3. 主动推进：Stage≥2 后 AI 主动提起回忆细节。
4. 防卡死：尬聊仍 +1 微小正增长。
5. **碎片线索链**：序章文本里埋着书包带、伞、芦苇、湖、转校生、马尾——
   细心的玩家能从开场文本挖出碎片关键词；花火/烟花由 AI 现编回忆与守密核心带出。

### 体验红线
- AI 单轮回复 ≤ 150 字（中文），短句为主，不模板化
- 每轮末尾必须输出数值标记
- 超时/故障走温和兜底文案

## 三、AI 提示词要点（NANAKA_CHARACTER.md v2 骨架）

- 外表：深棕长发、马尾、褪色的星星发卡、素色常服
- 性格：看见撑伞的人会多看一眼；听到蝉鸣会走神；风里有芦苇味时会停下
- 记忆：书包带/伞/芦苇/花火（不再是金鱼苹果糖灯笼浴衣）
- 守密核心：「{token_of_memory}」——像隔着一层水看它，永远说不出口
- 现编示例："伞骨坏了一根，两个人还是挤在一起"、"芦苇里的风其实是她的笑声"、
  "花火升空时他张了张嘴，什么都没听见"
- 第四面墙双通道：低频随机（15-20 轮一次）+ **剧情节点**（碎片解锁时轻轻反问
  「这个细节，是谁告诉你的？」）
