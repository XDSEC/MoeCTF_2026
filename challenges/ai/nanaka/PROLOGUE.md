## 1. 回忆（转校生）
```
那个夏天的起点，你已经记不清了。

高二下学期，班主任领着一个女生走进教室。
“这是新来的转校生，七夏。”
她站在讲台上，目光轻轻扫过全班，没有太多表情。
简短地说了名字，便不再多言。

你抬头看向她，心跳莫名地漏了一拍。
不是因为她好看——虽然确实如此。
而是某种说不清的感觉。
像是翻开一本很久没读的书，闻到一股熟悉的纸墨味，
却想不起什么时候读过。

她被安排在斜前方的空位上。
坐下时，她下意识地把书包带在手指上绕了两圈。
这个动作让你恍惚了一下。
好像很久以前，也有谁会这样。

但你想不起来了。
```

## 2. 重逢（湖边雨）
```
许多年后的夏天，你回到老家。
傍晚，你独自走到了小时候常骑车来的湖边。
湖水连着远处的山，芦苇沿着湖岸疯长，风一吹就沙沙地响。
这么多年过去了，这里居然还是老样子。

雨是忽然落下来的。
细密的雨丝打在水面上，湖面反倒静了下来。

然后你看见了她。
不远处的岸边，一个女生撑着伞，站在雨里。
她没有看你，视线落在湖面上，像是在看很远的地方——
远到雨雾都盖不住。

她似乎察觉到了什么，微微偏过头。
隔着一层雨雾，你和她的视线撞在了一起。
那一瞬间，心里像是被什么东西轻轻拨了一下——
很轻，却很清楚。

可你怎么都想不起来，这种感觉从何而来。

她像是认识你，又像从不认识你。
她只是看着你，轻声说出那句话——
一句你听不懂、却让你心里发酸的话。
```

## 3. 目标明示
```
她似乎忘记了什么重要的事情。
而你，好像就是那把钥匙。

——这个夏天，只有一次机会。
把她的好感度拉满，让她重新想起你。

她忘记的事，散落在这个夏天说出口的细节里。
（另有传闻：只要对她说出某个MISC深处的“信物”，
她便会想起一切……）
```

## 4. 演出衔接
```
七夏安静地站在雨里，等你开口。
对话开始。
```
