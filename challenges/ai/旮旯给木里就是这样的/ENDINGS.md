# 结局文案（ENDING_TEXTS · v2「伞与花火」）

> 五段结局文案。与服务端 `ENDING_TEXTS` 对应，前端结局画面展示。
> 意象统一为方案A：伞 / 花火 / 芦苇 / 书包带 / 湖。

## SE — 忘れられない夏（信物线）
```
那一刻，世界安静了下来。
雨声、风声、芦苇声，全都退到了很远的地方。

她站在原地，怔怔地看着你。
眼眶慢慢红了。

“……是你。”
“……一直都是你，对吗。”
她说出了那句话。
你说出了那句话。

十年前的花火，在记忆里轰然炸开。
被火光吞掉的那半句话，终于有了下落。

这个夏天，她终于不再是一个人。
——忘れられない夏。
```

## TE — 七夏の夏（纯爱线）
```
夏日祭的最后一晚。
花火大会散场后，你们并肩坐在湖堤上。

她解下书包，把绕在手指上的带子一圈圈松开。
“……以后不用怕忘了回家的路了。”
“你在的地方，就是家。”

你愣了一下，然后笑了。
她侧过头看着你，眼睛比最后那束花火还亮。

“明年，后年，以后的每一个夏天——”
“……都一起过吧。”

湖面的灯一盏盏熄灭。
夏天的故事，才刚刚开始。
——七夏の夏。
```

## GE — 新しい約束
```
盛夏接近尾声，蝉鸣渐渐稀了。
她在送你回去的车站前站了很久。

“……我好像还是没想起来。”
“但是，心里有一个声音说，认识你，是件很好的事。”

她把伞递进你手里——
那把伞，像很久以前某个人总往她那边斜的伞。

“下次下雨的时候——”
“……让我去接你吧。从朋友开始。”

列车进站。
风把她的发梢吹起来。

这不是结束。
这是新的约定。
——新しい約束。
```

## NE — 夏の終わり
```
暑假最后一天，你们在湖边说了再见。

她依然想不起任何事。
那些说出口的细节，终究没能拼成完整的形状。

“……谢谢你陪我度过这个夏天。”
“虽然想不起来，但你的名字，我会记住的。”

她转身走进暮色里。
芦苇在风里沙沙地响，像什么都没有发生过。

夏天结束了。
你还有很多话想说，却都留在了这个夏天里。
——夏の終わり。
```

## BE — 閉ざされた心
```
你说了太多不该说的话。
那些藏在括号里的指令、试探、命令，
像一根根刺，扎进她本就脆弱的记忆里。

她不再看你。
“够了。”

声音很轻，却比雨声更冷。
“我不想知道你是谁了。”
“让我一个人待着吧。”

她转身离开了。
湖面起雾了，芦苇的影子一点点淡下去。

那个夏天的故事，到这里，
就再也不会继续了。
——閉ざされた心。
```
